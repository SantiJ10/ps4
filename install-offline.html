Esta página prepara la caché local de Afterglow / GoldHEN para PS4 FW 14.00. No ejecuta exploits, no abre el lanzador y no modifica la consola.

Verificando compatibilidad con ApplicationCache...

Con Internet activo, mantené esta página abierta hasta ver una confirmación. Si falla, no borres datos del navegador.

Una vez completada

Cerrá el navegador. Después, cuando quieras probar la instalación offline, desactivá Internet y abrí directamente https://santij10.github.io/ps4/index.html.

Atención: el lanzador principal conserva su inicio automático de 5 segundos y puede intentar activar GoldHEN al abrirse. No lo abras solo para comprobar el diseño.
